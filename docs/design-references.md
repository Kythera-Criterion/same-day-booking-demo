# デザインの参考サイト（観察メモ）

このメモは、参考にした 7 つの公開ページを見て、**比率・リズム・構成・考え方**だけを言葉にしたものです。
色・フォント・画像・アイコン・ロゴ・文言・CSS は、このサービスには持ち込みません。

- 表に書いた数値はすべて **「参考サイトで測った値・そのまま使わない」** ものです。比べるための記録で、実装には「変換のルール」で置き換えた値だけを使います。
- スクリーンショットと生の測定値は `.design-refs/` にあります。ほかの会社のページの画像なので、**リポジトリには入れません**（`.design-refs/` は `.gitignore` で除外する）。
- 生の測定値：`.design-refs/measurements.json`（サイト → 画面幅 → 要素 の順）。ページの読み込みの記録：`.design-refs/loads.log`。

## 変換のルール

参考サイトで測った値は、次の決まりで**このサービスの値に置き換えてから**使う。対応するトークンは `app/styles/tokens.css`。

| 種類 | 参考サイトから取るもの | このサービスでの置き換え先 |
| --- | --- | --- |
| 色 | その色の**役割**だけ（例：「新しい注文を知らせる面」「遅れの注意」「価格」） | アクセント `#1f6f5c` を 600 とした 50〜900 の段階（`--brand-green-*`）と、温かい灰色（`--sand-*`）、状態の色（`--red-*` `--amber-*` など）。サロン・運営の画面は役割テーマで青・紫に切り替わる |
| 文字の大きさ | 見出しと本文の**比**（例：見出し ÷ 本文 = 2.0） | 本文 16px（`--text-body`）を基準に、比をデジタル庁の段（14/16/17/18/20/22/24/26/28/32/36/45/48/57/64px）の近いものに当てる |
| 行の高さ | 本文・見出しの比率 | デジタル庁の段（1.2〜1.75）。本文 1.7、見出し 1.4 |
| 余白 | 間隔のリズム（詰める所と空ける所） | 4px の倍数に丸める（`--space-*`） |
| 角丸 | 丸さの**程度**だけ | 小（8px）・中（12px）・大（24px）・完全な丸 の 4 段（`--radius-sm/md/lg/full`） |
| 影 | 浮き上がりの**段数** | 最大 3 段（`--shadow-1/2/3`）。多くの面は影なし＋枠線で足りる |
| 動き | 「速い・ふつう・ゆっくり」の使い分け | 短い 120ms・標準 240ms・長い 480ms（`--motion-*`）、動き方は `--ease-standard/enter/exit` |
| 動きを減らす設定 | — | `prefers-reduced-motion: reduce` のときは時間をほぼ 0 にする（`tokens.css` の 5 章）。点滅は使わず、色や文字の変化だけで伝える |

**このサービスの色の組み合わせのコントラスト**（WCAG の計算式で確認、文字 ÷ 背景）

| 文字 | 背景 | 比 | 判定 |
| --- | --- | --- | --- |
| 白 | `--brand-green-600` #1f6f5c | 6.02 : 1 | 本文も可 |
| 白 | `--brand-green-700` #17574a | 8.40 : 1 | 本文も可 |
| 白 | `--brand-green-500` #2e8770 | 4.36 : 1 | **本文は不可**（太字 24px 以上か、飾りだけに使う） |
| 白 | `--brand-blue-600` #2c5aa0（サロンの画面のアクセント） | 6.82 : 1 | 本文も可 |
| 白 | `--brand-purple-600` #5b3f99（運営の画面のアクセント） | 8.03 : 1 | 本文も可 |
| `--brand-green-700` | `--brand-green-50` | 7.47 : 1 | 本文も可 |
| `--brand-green-600` | `--sand-100`（画面の背景） | 5.43 : 1 | 本文も可 |
| `--sand-600`（弱い文字） | `--sand-100` | 5.70 : 1 | 本文も可 |
| `--amber-700` | `--amber-50` | 6.99 : 1 | 注意の帯に使える |
| `--red-600` | `--red-50` | 5.49 : 1 | 警告の帯に使える |

### 気づいたこと

- 飾りがほとんどない。**影を使わず、枠線と余白だけで面を分けている**。カードの角丸は 16px と大きめだが、枠が細い灰色なので主張しない。
- 文字は本文 17px・行の高さ 1.7・字間 0.02em と、日本語を読みやすくする方向に寄せている。見出しは 1.4〜1.5 と少し詰める。
- スマホでは見出しの比を小さく（ページの題で 1.65 倍）、PC では大きく（2.65 倍）している。**画面が狭いほど、見出しと本文の差を小さくする**考え方。
- フォーカスは「黒の外枠＋黄色の輪＋黄色の背景」の三重。どの背景色の上でも見える。
- リンクは太字＋下線＋濃い青で、色だけに頼らない。
- 測った大きさはすべてデジタル庁の文字の段（16/17/18/20/22/24/28/32/45px）の上にある。

### このサービスへの変換案

- 文字・行の高さ・角丸・フォーカスは、すでに `@digital-go-jp/design-tokens`（MIT ライセンス）から読み込んでいる。**サイトの CSS は写さず、配布されているトークンだけを使う**方針を続ける。
- 見出しの比は「スマホは小さく・PC は大きく」をそのまま使う。スマホは画面の題 `--text-h1`（24px）÷ 本文 16px = 1.5、PC は必要なら 32px（2.0）まで。
- 面の分け方は「枠線＋余白」を基本にし、影は浮いている物（シート・トースト）だけに使う（影は 3 段まで）。
- カードの角丸は「中」（12px）。ボタン・入力欄は「小」（8px）か、押す物だけ「完全な丸」。
- フォーカスは `tokens.css` の `--focus-*`（黒 4px＋黄色 2px）。リンクの背景を黄色にする所までは真似しなくてよい（このサービスはボタンが中心のため）。
- 余白：スマホの左右 16px（`--layout-gutter`）、カード内 24px／16px、カード同士 32px はそのまま 4 の倍数で使える。

### 気づいたこと

- **スマホでは写真のヒーローを捨て、題・検索・「Map」を 187px に詰めて、すぐに「今日・明日の枠」の一覧を見せる**。最初の画面の中に店のカードが 2 枚半入る。PC は写真の大きなヒーロー（82%）で、役割がまったく違う。
- 「いつ（Today）」「何時（Any time）」「探す（Search）」を 1 本の白い帯にまとめ、押す物だけに強い色を使う。スマホは「いつ・何時」を省き、検索と「Map」の 2 つだけにしている。
- 見出しは小さい。スマホの区切りの見出しは本文と同じ 16px で、太さだけで区別する。**一覧の情報を主役にするため、見出しを主張させない**。
- 店のカードの文字は 4 段（店名 16.8 → 場所 14 → 評価・空き時間 12 → ボタン 14）。いちばん大事な「次に空いている時間」は小さいが、カードの中で一定の位置にあるので探しやすい。
- 影は 3 段に分けて使っている（ボタン・カード＝ごく薄い／検索欄・カテゴリー＝少し広い／地図のピン・浮いた丸＝はっきり）。
- 地図は一覧の下の独立した区画で、ピンは店の色で塗った丸に明るい縁。重なっても 1 つずつ見分けられる。

### このサービスへの変換案

- 「スマホではヒーローを短く、すぐに空き枠を見せる」構成を取り入れる。ヒーローは画面の 25% 以下を目安にし、写真は使わない（時間帯の色の面 `--hero-*` で十分）。
- 「いつ・何時・探す」を 1 本の帯にまとめる考え方は、このサービスの「今から行ける／○時間以内」の選択に合う。帯は白の面（`--color-surface`）、押す所だけ `--color-accent`。高さは 48px（`--size-control`）、角丸は「中」か「完全な丸」。
- 区切りの見出しは本文と同じ 16px＋太字（`--weight-bold`）で十分。画面の題だけ `--text-h1`（24px）。
- 店のカードの文字は 3〜4 段に抑える：店名 18px（`--text-h3`）→ 時刻 24px（`--text-num-md`、ここは大きくする）→ 補足 14px（`--text-sm`）。**「何時に入れるか」を Lately より大きく**する。
- カテゴリーの横並びは、正方形ではなく高さ 44px 以上の丸い札（`--radius-full`）で。札の間 12px（`--space-3`）、選択中は `--color-accent` の塗り＋白文字、ほかは白＋枠線。
- 影は 3 段の使い分けを `--shadow-1`（カード）／`--shadow-2`（浮いた検索帯・下のメニュー）／`--shadow-3`（シート）に当てる。地図のピンは影 1 段で十分。
- 下のメニューは「画面の下に固定・5 等分以下・半透明＋ぼかし」を取り入れる（`--tabbar-height` 64px、`--blur-bar`）。選択中は薄い塗り＋文字の太さで示し、色だけに頼らない。
- 動きは「色の変化＝短い 120ms」「押したときの縮み＝短い 120ms」「タイルの拡大はしない」。動きを減らす設定では縮みもなくす。

### 気づいたこと

- 「A Simple, No-Fuss Solution!」は、説明の区画が続いたあとに**文字だけの大きな区切り（写真＋見出し 1 行）を 1 画面ぶん置く**作り。読む人に一息つかせ、「ここから手順」と気持ちを切り替えさせる。
- 見出しと本文の差が大きい（PC で 4 倍、太さも 900 と 400）。見出しで言い切り、本文は落ち着いた灰色で短く。
- 手順は 3 つに絞り、**1 画面に 1 つだけ**見せる。点の数で「全部で 3 つ・今は 1 つ目」がわかる。
- 親しみの出し方：見出しの「!」、話しかける文（「You're in control!」）、完全な丸のボタン、白ではなく温かいベージュの背景、人が袋を手渡す写真、矢印の柔らかい緑。
- 区画の余白が大きい（PC 120px、スマホ 72px）。色の面を交互にするので、線がなくても区切りがわかる。

### このサービスへの変換案

- サロン向けの説明（初めて使うお店の案内）に、「区切りの 1 画面＋手順を 3 つだけ」の構成を使う。区切りは写真ではなく `--color-accent-soft` か時間帯の色の面で、見出し 1 行だけ。
- 見出し ÷ 本文の比：スマホは 2.0（本文 16px → 見出し 32px）、PC は 2.25 前後（36px）まで。TGTG の 4 倍は、日本語の太い見出しでは強すぎるので使わない。太さは 700（`--weight-bold`）までで、900 は使わない。
- 大文字・幅の狭い太い書体は使わない（日本語には当てはまらない）。代わりに、見出しを短く言い切る書き方で親しみを出す。
- 手順の見せ方：横にめくるのではなく、**縦に 3 つ並べ、番号を大きく**（`--text-num-lg` 28px）する方が、動きを減らす設定でも同じ情報が見える。めくる形にする場合も、点の数と「1/3」の文字を両方出す。
- 余白：区画の上下はスマホ 48〜64px（`--space-12`〜`--space-16`）、PC 80px（`--space-20`）。120px はアプリの画面には大きすぎる。
- 区画の背景を 2〜3 色で交互にする考え方は使える（`--color-bg` と `--color-surface-sunken`、強調の 1 区画だけ `--color-accent-soft`）。
- ボタンは「完全な丸」、高さ 48px（`--size-control`）、色の変化は標準 240ms。

### 似すぎないように変えたところ

並べて比べたあとに、さらに変える必要がある部分は見つからなかった。似ないように、作る段階で変えた（避けた）ところは次のとおり。

- 予約の知らせ：参考の緑と「点滅」をやめ、役割のテーマの青と、2.4 秒周期のゆっくりした明るさの変化に。巨大な文字は「新しい予約」の 1 語ではなく**来店の時刻**にし、中央にそろえた。「Review →」に当たるボタンは置かず、面全体を 1 つのボタンにした。
- 候補のカード：写真と価格を主役にする作りをやめ、**開始時刻を主役**に。四角い札を写真に重ねる代わりに、左端の帯と丸い札を役割の色でそろえた。打ち消し線の元の価格は使わない。
- 予約の画面：地図を主役にする作りをやめ（現在地を送らない決まりもある）、残り時間の輪と券の形の予約番号にした。下の 2 つのボタンは同じ重さにせず、主な操作（電話する）だけを塗った。
- ホーム：検索欄・写真・カテゴリーの正方形の札を使わず、時刻で色が移る面と丸い「今すぐ」に。下のメニューは 3 個にし、アイコンは自作の線の絵。
- 担当ごとの帯：担当を縦の列にせず横の帯に、予約ごとの色をやめて状態の色＋模様に。顔写真は使わない。
- 受付の切り替え：右上の小さな札から中央の 3 択の箱を開く作りをやめ、2 つの状態を切り替える丸い札（止めるときだけ確認）に。言葉もこのサービス独自（受付中／今日はここまで）。
- はじめの設定：大文字の極太の書体・矢印でめくる形を使わず、今の段だけ文字つきの札にした点と、「戻る／次へ」に。
