# 見た目の作り直し：参考サイトの観察と、このサービスへの調整

このサービス（当日・直前の空き枠だけを、今から行きたい人へ届ける）の見た目を作り直すために、日本で運営されている4つのサロン予約サービスの CSS・色・フォント・画像・アイコンを実際に確かめ、その仕組みを理解したうえで、このサービス向けに調整・発展させた記録です。

- 参考サイトのロゴ・サービス名・キャッチコピー・画像・フォントファイル・CSS のコードはそのまま使っていません。値と書き方の「関係」を取り入れ、色相・明度・形を変えて、自分のコードとして書いています。
- 取得したスクリーンショット・CSS・測定結果は `.design-refs/`（git の対象外）にあります。
- 作り直しの前後の画面は `docs/screens/before/`・`docs/screens/after/`（390×844 と 1024×768、同じ状態で撮影）。

## 1. 確かめ方

| 項目 | 内容 |
|---|---|
| 開いたページ | 各サイトのトップ・一覧・詳細を1つずつ（スマートフォン＝Playwright の `iPhone 13`、PC＝1280×800 で各1回）。ページ間は2.5〜3秒あけた。App Store は minimo と Nailie Beauty の掲載ページを PC 幅で各1回 |
| 読み込み | 計26回、すべて 200。ブロック・CAPTCHA・403 はなし（ログインが必要なページは開いていない） |
| CSS | ページが読み込んだスタイルシートのレスポンスを、そのまま `.design-refs/css/<site>/` に保存（追加の取得はしていない）。要素に実際に効いているルールは、Chrome の開発者向けの機能（CDP の `CSS.getMatchedStylesForNode`）で `snippets.css` に抜き出した |
| 計算された値 | 主要な要素ごとに `getComputedStyle` で、文字（font-family・font-size・font-weight・line-height・letter-spacing）、色（color・background-color）、形（border・border-radius・box-shadow）、余白（padding・margin・gap）、画像（aspect-ratio・object-fit）、動き（transition）を `measure-*.json` に記録 |
| 色 | `:root` などの CSS 変数と、画面に出ている色の出現回数を、役割ごとに整理 |
| フォント | `font-family` の指定、`@font-face`、`document.fonts`（読み込まれた Web フォント） |
| 画像・アイコン | 写真の題材・比率・切り抜き・文字の重ね方、アイコンの線か塗りか・大きさ・文字との間隔 |
| 小さな操作 | アプリへの誘導の窓は「閉じる」を押した。楽天ビューティの iframe のポップアップは、手元の画面だけで非表示にして撮影した（サーバーには何も送っていない） |

## 2. トーン：「澄んだ」「間に合う」「確か」

minimo が掲げる「クリーンであたたかく、心がはずむ」と重ならないよう、先にこのサービスの言葉を決めた。色・文字・写真・アイコンの選び方は、すべてこの3つから説明できるようにしている。

| 言葉 | 意味 | 見た目への反映 |
|---|---|---|
| **澄んだ** | 余計なものがなく、すぐ見通せる | ベージュをやめ、わずかに青緑に寄せた白（`#f5f8f7`）の背景に、枠線も影もない白い面を置く。色は「操作」と「時間」の2つだけを強く使う。写真は彩度を 0.88 倍に抑えてそろえる |
| **間に合う** | 今から行ける・急ぐべきものが分かる | 開始時刻と残り時間を数字のフォント（Manrope）で大きく。受付締切が近いものだけ琥珀の「時間の色」。「今」に関わるアイコンは2色（duotone） |
| **確か** | 1回の操作で予約しても不安にならない | 見出しにはアイコン、ルール（店頭払い・キャンセルはお店に電話・受付締切）は必ず同じ場所。補足も 12px 以上・4.5:1 以上。予約番号は券の形で大きく |

## 3. 参考サイトごとの記録

### 3-1. minimo（ミニモ）

開いたページ：トップ https://minimodel.jp/ ／ 一覧 https://minimodel.jp/list/1/14/4/0 （表参道・ヘア）／ 詳細（スタイリストのページ）／ App Store の掲載ページ

**確かめた値と CSS の書き方**

| 役割 | 値 |
|---|---|
| 一覧のカード | 背景 #fff、角丸 10px、**線なし・ぼかした影** `0 0 15px #bfcbde66`、内側の余白 16px |
| ラベル（塗り） | 「新規」#ff8490／白、「全員」#51b0e1。11px／700、行高 14px、余白 3px 8px、**角丸 2px**（38×20px） |
| ラベル（線） | 「ミニモ限定」白地・線 1px #e6ebee・文字 #0d92c3 11px／700、角丸 2px |
| 線を引いた価格 | 通常 `¥24,200` 10px #888 `text-decoration: line-through`（span）→ 三角の画像 → 特別 `¥12,100` 14px／700 #444 → 淡いピンクの箱 #fef0f2 に「本日来店で¥9,900」#fd4a5b |
| 駅からの時間 | 電車のアイコン 12px（#888）＋ 12px「表参道駅1分 / …」1行で省略 |
| 検索の絞り込み | メニュー・エリア・日時・価格帯を、同じ形の 48px の行（線 1px #0d92c3・角丸 8px・アイコン 16px）にそろえる |
| カテゴリのチップ | 高さ 40px・角丸 32px（丸い）・線 #0d92c3、選択中は背景 #e7f5f9＋太字 |
| 文字 | 見出し 18px／700、本文 14px／21px、補足 12px／18px・11px・最小 10px。色は #444／#888 |
| フォント | `"Hiragino Kaku Gothic ProN","Helvetica Neue",Meiryo,…`（Web フォントなし） |
| 写真 | 86px の正方形・線 1px・角丸 4px・間隔 4px で横に流し、カードの端まではみ出させる。詳細の上部 390×180 に `linear-gradient(#0000,#00000080)` を重ねて白い文字 |
| アイコン | 塗りの SVG を `mask-image` で `::before` に当て、背景色で色を付ける（12・16・20・24px） |
| CSS 変数 | `:root` は2つだけ。部品ごとに `--bg-color`・`--fg-color`・`--border-color`・`--icon-size` を切り替える作り |
| 主な色 | ブランド・リンク・選択 #0d92c3、予約・価格・割引 #fd4a5b（グラデーション #ff8490→#fd4a5b）、文字 #444／#888、線 #e6ebee、背景 #f2f2f2 |

書き方の要点（`.design-refs/minimo/snippets.css` より）：
```css
.label { color: var(--fg-color); background-color: var(--bg-color); border-radius: 2px; padding: 3px 8px; font-size: 11px; font-weight: 700 }
.label.newbie { --bg-color: #ff8490; --fg-color: #fff }
.undiscountedPrice { color: #888; font-size: 10px; text-decoration: line-through }
.recruitmentTitle { display: -webkit-box; -webkit-box-orient: vertical; -webkit-line-clamp: 2; overflow: hidden }
.photoGallery { display: flex; gap: 4px; margin-inline: -16px; padding-inline: 16px; overflow-x: auto }
```

**長所**
- カードを見ただけで「今行けて、お得」が伝わる（ラベル＋線を引いた価格＋当日の価格の3段）。
- ラベルを `--bg-color`／`--fg-color` だけで出し分ける作りで、塗り（新規・全員）と線（限定）の役割が分かれている。
- 写真の列をカードの端まではみ出させ、続きがあると分かる。

**このサービスでどう調整・発展させたか**
- 割引ではなく「今行ける」を伝えるので、ラベルを**3種類の文法**に整理し、**形で意味を分けた**（`components/ui/Label`）。
  - 時間のラベル：塗り・時間の色（琥珀 #9d5d03）・時計のアイコン（「受付あと12分」「いちばん早く始まる」）
  - 条件のラベル：枠線だけ（「女性限定」「いちばん近い」）
  - 価格：ラベルにせず、太い数字（Manrope 800）＋小さな「当日価格」（`components/ui/Price`）。線を引いた価格は使わない（当日価格は割引ではないため）
  - 1枚のカードに付けるのは2つまで。角丸は 2px ではなく 6px、文字は 11px ではなく 12px（補足の最小）にして、minimo のラベルと形を変えた。
- 部品ごとの変数で出し分ける考え方は、`Label.module.css` の種類別クラスと、トークンの意味の値（`--color-time`・`--color-line-strong`）に置き換えた。
- 「表参道駅7分」の考え方を発展させ、距離に加えて**歩く人のアイコンと「徒歩約7分・530m」**を出す（80m を1分として、端末の中で計算）。担当が決まっている枠は「担当 佐藤（ショート・メンズカットが得意）」と、美容師の得意なスタイル（`stylists.styles`）を1行で出す（`components/user/CandidateCard`）。
- 写真の横の流れ（はみ出し）は、ホームの「今日、空きのあるお店」に使った。影で浮かせるカードはやめ、背景の色の差で分けた。

### 3-2. Nailie Beauty（ネイリービューティー）

開いたページ：トップ https://nailie.jp/ ／ 一覧 https://nailie.jp/search?…（東京都・ネイル）／ 詳細（ネイリストのページ）／ App Store の掲載ページ

**確かめた値と CSS の書き方**

| 役割 | 値 |
|---|---|
| トップ | メインビジュアル・3ステップ・特徴・比較表は**画像**（文字の大きさは画像に焼き込み）。3ステップは「灰色の角丸の面（アプリのアイコン・画面）→ 下向きの山形 → 太字の見出し」を縦に積む |
| クーポンコードの枠 | 画像の上に重ねた HTML。「コード：」と「NB10000」は M PLUS Rounded 1c 700、`clamp(1.125rem, …6.32vw, 4.6rem)`、字間 .08rem、#e029c1。白い枠と線は背景画像。コピーのボタンは #df34ce・白 15px／800・**角丸 32px** |
| 写真のグリッド | スマートフォン3列・PC 4列、**間隔 0〜2px**で端から端まで。正方形は `padding-bottom:100%`＋`object-fit:cover` |
| 写真の上の価格 | 右下に `rgba(0,0,0,.5)`・角丸 7px・11px 白 |
| 空き状況 | カードの下に「今日 × ／ 明日 △ ／ 明後日 ◯」を1行 |
| カード | 背景 #fcfbff・線 1px #eee・角丸 4px・影 `0 2px 8px rgba(181,181,181,.15)` |
| 詳細 | カバー写真にカード（角丸 30px）を −140px で重ね、140px の丸いアバター |
| フォント | `"Noto Sans JP"`（Google Fonts 400／500／700）、アイコンは icomoon のアイコンフォント（塗り） |
| 主な色 | マゼンタ #e9319e・予約 #e50250（グラデーション）、アクセントのティール #009193、文字 #484848、補足 #858585、線 #eee |
| 写真の調子 | 手元とネイルのアップ。明るく、暖かいピンク寄り、彩度が高い |

書き方の要点：
```css
.post-thumbnail__img::before { content: ""; display: block; padding-top: 100% }
.post-thumbnail__img img { position: absolute; object-fit: cover; object-position: center }
.post-thumbnail__tag.type-price { border-radius: 7px; background: rgba(0,0,0,.5) }
.couponCode__number { font-size: clamp(1.125rem, -.1386rem + 6.3182vw, 4.6rem); letter-spacing: .08rem }
```

**長所**
- 写真が最初に目に入り、写真から選んでそのまま予約へ進める。
- 3ステップの説明が「絵 → 一言」の繰り返しで、読まずに分かる。
- クーポンコードを大きく、`clamp` で画面幅に合わせる。

**このサービスでどう調整・発展させたか**
- 候補カードの右上に、お店の**小さな正方形の写真**（76px・角丸 12px）を置いた。写真を主役にしつつ、主役は開始時刻のまま（`CandidateCard`）。
- 予約の確認シートと予約確定の画面では、上部に **16:9 の写真**を置き、下に向かって暗くなるグラデーション（`--photo-shade`）の上に店名と開始時刻を重ねた（`components/ui/SalonPhoto` の `caption`）。
- 撮影者の違う写真が1つのサービスに見えるよう、書き出すときに明るさ・色温度（赤と青の差を3割縮める）・彩度（0.88倍）をそろえた（第5章）。Nailie の高彩度・ピンクの調子とは逆に、彩度を抑えた澄んだ調子。
- 「3STEPで簡単予約」は、**はじめて開いた人にだけ**出す「押す → 選ぶ → 行く」の横並び（番号つきのアイコン）にした（`components/user/FirstSteps`。「わかった」で閉じると、その端末では出さない）。
- クーポンコードの枠は、予約確定の画面の**予約番号チケット**に発展させた。左右の切り欠き（`radial-gradient`）と点線で券の形にし、番号は Manrope 800・56px。受付で見せる番号なので、コピーのボタンは付けない（`BookingDetail`）。

- 確定の操作（スライドと長押し）は、シートの下に残す（スクロールしても見える）。

**このサービスでどう調整・発展させたか**
- ホームに、**検索欄に似た細長い形**の「話しかけて探す（プレビュー）」の入口を置いた（虫眼鏡＋マイクのアイコン。`components/user/VoiceSearch`）。グラデーションの枠線も灰色の線も使わず（線はポインタを重ねたときだけ）、背景との色の差だけで見せる白い面にし、マイクを淡い操作の色の四角に置くことで、楽天ビューティの入口・検索欄と形を変えた（第8章）。開くと、既存の将来構想のプレビュー（言葉の決まりで読み取る）につながる。
- バナーはたくさん並べず、「**実証実験中：手数料・キャンセル料はかかりません**」の落ち着いた帯を1本だけ置いた（`components/ui/Notice` の `NoticeBand`。上下の細い線だけで、色を塗らない）。
- 下に固定の操作（電話は線・予約は塗り）の考え方は、サロンの画面の下のバー（今日／枠を出す／設定）と、予約確定の画面の「地図を開く（線）／電話する（塗り）」に使った。

### 3-5. サロンの画面（業務用の表示）

参考の4サイトは利用者向けなので、サロンの画面は、上で決めたトークンを使う「業務用の表示」にした。

- 時刻と予約番号を大きく（Manrope 800）、背景と文字のコントラストを高く（予約の知らせは藍の最も濃い段 #0f2242 に白、15.8:1）。
- 状態（公開中・予約あり・来店済み・取り下げ）は、色だけでなく、**アイコン・塗り・枠線・模様**でも区別する（`components/salon/SlotStateMark`）。

| 公開中（予約待ち） | 白 | 役割の色の点線 2px | — | 時計（Clock） |

## 4. 決めた値（`app/styles/tokens.css`）

基本の値（例：`--teal-600`）と、意味の値（例：`--color-action`・`--color-time`・`--radius-label`）の2段。画面の CSS は意味の値だけを使う。

### 4-1. 色

**出発点**：参考サイトで測った「役割ごとの色の関係」を取り入れた。
- 主要なボタンとラベル：どのサイトも、主要な操作の色（minimo #0d92c3→#fd4a5b、Hot Pepper #d36985、楽天 #cc5777）と、ラベルの塗り（明るめ）・線（灰色）を分けている → このサービスでは「操作＝青緑の塗り」「時間＝琥珀の塗り」「条件＝灰色の線」に。
- 価格：minimo・Hot Pepper・楽天は価格に色を付ける（#fd4a5b・#c43357・#cc5777） → このサービスでは**色を付けず**、太さ（800）と大きさで目立たせ、強い色を「操作」と「時間」だけに残した。

### 4-2. フォント

| 参考サイト | 指定 |
|---|---|
| minimo | ヒラギノ・Helvetica Neue・メイリオ（Web フォントなし） |
| Nailie Beauty | Noto Sans JP（Google Fonts）、LP に M PLUS Rounded 1c |
| Hot Pepper | Helvetica（スマートフォン）・メイリオ（PC） |
| 楽天ビューティ | メイリオ・Arial |

- 参考サイトは端末の標準のゴシック（ヒラギノ・メイリオ）が中心で、丸い字（M PLUS Rounded）は「あたたかい・はずむ」側にある。このサービスは「澄んだ・確か」なので、細身で端正な **Zen Kaku Gothic New** を選んだ。その後の刷新で、字面が締まっていて数字の欧文（Manrope）となじむ **M PLUS 2**（可変フォント）に替えた。どちらも参考サイトと同じ字ではないので、見分けもつく。
- 時刻・金額・予約番号は、幾何学的で桁の形がはっきりした **Manrope**（500・700・800）を組み合わせ、`font-variant-numeric: tabular-nums` で桁をそろえた。
- どちらも Google Fonts の SIL Open Font License。`next/font/google` で読み込み、参考サイトのフォントファイルはダウンロードしていない。

### 4-3. 文字の大きさ

参考サイトの「見出し・本文・補足」の比率（minimo 18／14／12、Hot Pepper 16／12／10、楽天 16／12／10）は、補足が 10〜11px まで下がる。このサービスでは比率（見出し≒本文×1.3〜1.5、補足≒本文×0.75〜0.85）を取り入れつつ、補足を 12px 未満にしない段階に置き直した。

| 意味の値 | 大きさ | 使い道 |
|---|---|---|
| `--text-caption` | 12px | 補足・ラベル |
| `--text-small` | 14px | 本文（密な所）・操作 |
| `--text-body` | 16px | 本文・入力欄（ズームを防ぐ） |
| `--text-title` | 20px | 小見出し・シートの見出し |
| `--text-heading` | 28px | 画面の見出し・写真の上の店名 |

### 4-4. 余白・角丸・面と影・動き

- 余白は 4px の倍数（`--space-1`〜`--space-16`）。
- 角丸は4種類：ラベル 6px（参考 2〜4px より少し丸く）・操作 10px（参考 4〜8px）・面とシート 16px（参考 10〜12px）・写真 12px（参考 4px より丸く、面と合わせる）。完全な丸（999px）はやめた（minimo のチップ・Nailie のボタンの丸さと区別）。
- 面と影の規則（1つ）：**ページの背景の上に白い面を置き、背景の色の差で区切る。面に枠線も影も付けない。** 面の中は細い線か沈んだ面。影は浮いているもの（シート・下に固定のバー・知らせ）だけ。枠線は入力欄・条件のラベル・選択中の輪郭だけ。
  - minimo（ぼかした影でカードを浮かせる）と Nailie（線＋影）の中間ではなく、どちらとも違う「影も線もない面」にした。
- 動きは短い（120ms）・標準（220ms）・長い（420ms）の3段階。`prefers-reduced-motion` のときは 0 にし、`base.css` でもアニメーションを止める。
- 押せる部品は 44px 以上、フォーカスの輪郭は 3px の役割の色（`:focus-visible`）。

### 4-5. ページの背景：時刻の空（虹から変更）

はじめはページの背景に淡い7色の虹を敷いていたが、「サービスの考え方に合わせて現代的に」という依頼を受け、**開いた時刻の空の色**に替えた。虹はどの画面でも同じ明るさで、このサービスの「今日の、今の空き」と結び付いていなかったため。白い面・文字・ボタンの色は変えていない。

- 材料は、ごく淡い2色×4つの時間帯（`--sky-morning-a`〜`--sky-night-b`）。朝（5〜11時）＝青緑と淡い金、昼（11〜16時）＝澄んだ青、夕方（16〜19時）＝桃色と藤色、夜（19〜5時）＝藍。
- 時間帯は `<html data-sky="...">` で決める。`app/layout.tsx` の小さなスクリプトが、描画の前（ちらつかないように）と1分ごとに、日本時間の時刻から付け直す。スクリプトが動かない環境では昼の空。表示だけのもので、予約・表示の内容には関わらない。
- `base.css` の `body::before` に、画面に固定して敷く（スクロールしても動かない。押す操作は受けない）。ヘッダーと運営のタブは、白を半分重ねたすりガラス（`--color-glass`）。

| ページ | 特性 | 背景（`--page-wash`） |
|---|---|---|
| お客様 | スマートフォンで「今から行ける」を探す | 今の時刻の空を、斜め（170°）に画面いっぱいに |
| サロン | タブレットで1日中開いておく業務の画面 | ほぼ無地。上の端だけ藍をごく淡く（目が疲れないように） |
| 運営 | 数字とグラフを正しく読む | 無地。上の端だけ紫をごく淡く（グラフの色と混ざらない） |
| デモ用の舞台 | 3つの端末を並べて録画する | 左から右へ、朝から夜へ移る1日の空に沈んだ面を半分重ねる |

- コントラスト：8色それぞれの上で、ページに直接のる文字の色を計算で確かめた。最も低いもので、操作の色 #1f6f5c が 4.68:1、補足の文字 #555c5a が 5.33:1、時間の色の文字 #7e4a00 が 5.69:1。axe はグラデーションの上のコントラストを自動で判定できないため、計算で確かめた。
- コントラストを高くする設定（`prefers-contrast: more`）・強制カラー（`forced-colors: active`）・印刷のときは、無地にする。

### 4-6. 動き：「届く」「減る」「決まる」の3つだけ

飾りのために常に動くものは置かず、このサービスにしかない瞬間にだけ短い動きを付けた。長さは 4-4 の3段階のまま。動きを減らす設定では長さが 0 になり、すぐに最後の状態で表示される。機能（何が表示されるか・押したときの動き）は変えていない。

- **届く**：お客様の候補カードは、少し上から入る。開いている間に新しく届いた枠のカードには、時間の色の輪が1回だけ広がって消える（最初の読み込みとエリアの切り替えでは出さない。`UserHome` の `freshIds`）。
- **減る**：予約の画面の残り時間の輪は、表示したときに空から今の残りまで満ち、その後は少しずつ欠ける。残り10分で時間の色に変わる。分の数字は、1分進むたびに下から入る。
- **決まる**：予約した直後の画面では、「予約が確定しました」の印が弾むように現れる。
- サロンの画面は1日中開いておくので、今ある新着予約の知らせのほかは動きを足していない。

| `components/ui/*`＋`*.module.css` | 共通の部品：ボタン・ラベル・価格・お知らせと帯・面と見出し・入力・切り替え・知らせ・写真・アイコン |
| 部品ごとの CSS Modules | お客様：候補カード・詳細シート（時刻のチップ）・ホーム・予約確定・下部のタブ・はじめての3つの手順・話しかけて探す・距離レーダー。サロン：帯・タイムライン・一覧・予約の知らせ・状態の見分け方・営業の画面 |

- 論理プロパティ（`margin-inline`・`padding-block`・`inset-inline-start` など）を使う。
- 色や数値は画面の CSS に直接書かない（例外は線の太さ 1〜2px と、メディアクエリの境目 720px・960px）。
- 古い `app/globals.css` のクラス（`.card`・`.slot`・`.chip`・`.badge` など）は、置き換えのあと削除した。
